# 三端设计图与现有后端接口对齐审计

核对日期：2026-10-07。对象：M01–M08、W01–W08、A01–A08，共 24 张图板、64 个主页面／状态画板，以及当前工作区的接口文档、路由、DTO、VO、Controller 和 Service。64 个画板不等于 64 个页面路由。

## 结论

**核心业务流程有现成后端支持，但当前图片不能原样当作完全对齐的实现规格。** 主要问题是部分画面增加了后端没有的筛选条件、列表字段和个人资料；另有撤回恢复、历史记录、时间输入等交互需要纠正。没有必要因此重做三端布局，也不建议为了生图中的附加元素立即扩展后端。

页面与接口本来就是多对多关系。确认弹层、复制、图片放大、密码二次确认、清空筛选等不需要独立接口；举报对照页、我的总览等需要组合多个现有接口。不能把“不是一个页面对应一个接口”直接判定为缺接口。

本次运行 `rtk go test ./tests/router -count=1`，15 项测试通过。路由一致性测试确认文档列出的 37 个接口与实际注册一致。业务能力判断另结合源码；本次没有重新执行数据库集成、真实微信或三端端到端联调，路由测试不代表这些验证已完成。

另外三点应在精确稿中统一：

- A03 的 `superseded` 表示旧待审核记录被取代，不代表管理员已经审核。审核人和原因可能为空，应显示“系统结束／无人工处理”，不能填虚构管理员。审核、举报列表当前均按提交时间从早到晚，不提供任意列排序。
- A06 账号搜索实际是完整 `account_no`，不是数据库用户 ID；昵称支持包含查询。A07 相关帖子可通过 `author_id` 查询，但审核状态与完成状态应分开显示，不能混成一列互斥状态。
- “忘记密码／联系管理员”只能给出明确的线下联系说明；当前没有在线找回密码、客服会话接口。新密码不能与当前密码相同，改密页应补齐提示。

## 能组合完成，但不能误认成单接口完整返回

1. **我的总览**：个人资料、额度、我的帖子、未读数分别查询。通知打开时调用单条标读；加载列表本身不标读。没有批量已读、推送订阅或私聊接口。
2. **举报对照**：举报详情提供原版 `content_snapshot` 和当前状态指针，当前完整内容另取管理帖子详情。原版图片使用审核历史图片权限通道，必要时从帖子审核历史匹配 `post_revision` 对应的审核记录；不能直接把存储 Object Key 当公网地址。
3. **操作历史**：审核历史和操作日志提供各自真实事件。日志筛选支持目标帖子／用户 ID，不支持按 `target_report_id` 查询；不要承诺任意统一历史搜索或独立备注。
4. **结果通知**：用户端以通知实际 `title/content` 为准。用户没有管理举报详情权限；通知中的 `report_id` 不代表可以访问 `/admin/reports/:id`。后端通知没有结构化的举报处置动作字段，不能仅凭 ID 自行拼出“已下架／已禁用”的确定结论。

## 接口接入必须保留的行为

- **权限与会话**：受保护内容和图片需要认证；网页 Cookie＋CSRF，小程序 Bearer。未登录不能先预览真实帖子。小程序图片下载也必须携带认证，不能认为 `<image>` 直接使用受保护地址就一定成功。
- **新建与编辑**：新建保留同一次提交的 `Idempotency-Key`；编辑是完整内容替换，使用 `If-Match`。修改后进入待审核，不能继续把旧公开状态作为成功反馈。每日额度跨端共用，以接口为准。
- **状态修改与审核**：完成／撤回、下架、审核决定使用对应资源版本。举报决定的 `If-Match` 针对举报；执行下架还要提交当前 `expected_post_state_version`。冲突后重新展示内容，不自动覆盖。
- **动作权限**：使用详情的 `can_edit`、`can_complete`、`can_report`、`can_decide` 等标志，并遵守后端错误结果；管理员不能审核／处理自己帖子的相关事项。不可用动作不应只靠页面上看起来“是管理员”就开放。
- **表单校验**：校区、时间精度、联系方式类型使用既定枚举；图片最多 6 张、单张 5 MB、JPEG／PNG。前端补足逐字段提示，不能假设所有跨字段校验都会返回可直接定位输入框的结构化错误。
- **账号处置**：密码 8–32 个 Unicode 字符，不 trim；改密、换绑、退出的全端失效语义按接口处理。重置响应只当场交付，不能记录在日志或通知，也不能遇到超时就自动再次重置。

## 建议的收敛方案

保留现有视觉风格、三端导航和业务分工，先修正 D01–D12，再进入可编辑稿或前端实现。这样核心流程可以沿用现有 37 个接口，不需要新增业务模块。
