# 三端本地演示

设计依据：`design/apple-style-v2`。用户网页与管理网页使用 Vue 3 + Vite，小程序为原生 WXML / WXSS / JavaScript。三端连接同一 Go 后端，无模拟业务接口。

## 启动

在 `backend` 目录运行 `go run ./cmd/server`，需要现有 `configs/config.local.yaml`、MySQL、Redis 与 OSS 配置。

在 `frontend` 目录运行：

```sh
npm ci
npm run dev
```

- 用户网页：`http://127.0.0.1:5173/`
- 管理网页：`http://localhost:5173/admin`

本地演示使用两个主机名，以便同一浏览器同时登录普通用户和管理员；同一主机名内 Cookie 登录会共享。账号见本地忽略文件 `deploy/demo-accounts.local.json`，不要提交或公开其中密码。

微信开发者工具导入仓库下 `miniprogram` 目录。AppID 已采用现有项目配置；模拟器请求 `http://127.0.0.1:8080`。项目配置关闭域名校验仅用于本地模拟器；真机或发布前需设置合法 HTTPS 服务域名。微信绑定使用真实 `wx.login` 凭证，账号密码登录也可完成普通演示。

## 验证

```sh
node scripts/sync-domain.js
npm test
npm run build
```

校验逻辑以 `src/domain.js` 为源，通过上述脚本同步到小程序；避免手动修改 `miniprogram/utils/domain.js`。

建议演示流程：用户发布 → 管理员审核 → 用户首页查看 → 我的通知 → 本人帖子完成与恢复 → 编辑重审 → 审核历史。举报处理、下架、账号禁用和重置密码在管理端独立提供，均要求填写原因。临时密码仅在操作结果中展示，不写入日志。
