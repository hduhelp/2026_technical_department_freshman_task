# 三端实现与验证记录

日期：2026-10-07。范围为本地浏览器与微信开发者工具模拟器演示，未发布线上版本。

## 设计覆盖

24 张设计板中的 64 个主要页面与状态由以下页面和弹层承载，不创建 64 个独立路由。

| 设计板 | 实现入口 | 覆盖内容 |
| --- | --- | --- |
| M01 / W01 / A01 | `miniprogram/pages/login`、`pages/account`；`src/pages/Login.vue`、`Account.vue` | 账号登录、登录失败、强制改密；小程序微信登录和首次绑定 |
| M02 / W02 | `pages/home`；`Home.vue` | 列表、搜索、类型、校区、日期、完成状态、分页与空态 |
| M03 / W03 | `pages/detail`；`PostDetail.vue`、`PostContent.vue` | 寻物与拾物语义、完整联系信息、复制、图片预览、举报及反馈 |
| M04 / W04 | `pages/publish`、`utils/postForm.js`；`PostForm.vue` | 全部必填字段、三种时间精度、图片排序移除重试、重复联系方式、额度、提交结果 |
| M05 / W05 | `pages/mine`、`notifications`、`history`；`Mine.vue`、`PostDetail.vue` | 我的帖子与筛选、未读数、通知阅读、历史快照 |
| M06 / W06 | `pages/detail`、`edit`；`PostDetail.vue`、`PostForm.vue` | 完成与恢复、撤回确认、编辑重审、退回原因及只读状态 |
| M07 / W08 | 各页面加载与错误分支、两端 API 和表单模块 | 加载、不可访问、校验、网络失败、额度耗尽、会话失效、输入恢复、版本冲突 |
| M08 / W07 / A08 | `pages/account`；`Account.vue`、`api.js` | 只读资料、改密、全端退出；小程序绑定与换绑、绑定错误 |
| A01 / A02 / A03 | `Admin.vue` 审核模块 | 队列、筛选、完整快照、历史只读、通过、退回、拒绝及原因 |
| A03 / A04 | `Admin.vue` 帖子模块 | 全部帖子、筛选、管理详情、审核历史、下架原因确认 |
| A05 / A06 | `Admin.vue` 举报模块 | 队列、原版与当前内容对照、驳回、下架、禁用及冲突 |
| A06 / A07 | `Admin.vue` 账号模块 | 查询、详情、禁用、重置原因、一次性临时密码与复制 |
| A08 | `Admin.vue` 日志模块、登录与账号页 | 日志查询、前后状态只读详情、无权限、会话错误、改密 |

业务接入沿用 `docs/api-design.md` 的 37 个接口。网页使用 HttpOnly Cookie 与 CSRF，小程序使用 Bearer；创建携带幂等键，修改和管理决定携带资源版本。历史图片使用历史接口，小程序下载受保护图片时附认证。

## 已完成的运行验证

- 本地用户网页：登录、完整表单发布、搜索与筛选、带图详情、通知已读、完成及恢复、编辑重审、退回原因、历史快照、举报提交。
- 本地管理网页：审核通过与退回、带图内容、举报快照对照及驳回、查询筛选、操作日志、列表条件返回保留、账号处置确认对象与后果。
- 微信模拟器：账号登录、首页与个人中心、真实 OSS 图片上传、编辑重审、新帖发布、通知阅读、共用额度、账号设置与绑定确认页面。
- 三端真实共用帖子 43「银色头戴式耳机」及其图片；小程序提交的帖子 60「蓝色折叠雨伞」保留为待审演示数据。
- 小程序全端退出后，网页旧会话失效；重新登录成功，网页未提交表单恢复。修复了失效 HttpOnly Cookie 阻碍重新登录、同站多标签 CSRF nonce 轮换导致写请求失败的问题。

## 自动化检查

- `frontend`：`npm test`，4 项检查通过，包含共享校验、Cookie/CSRF/If-Match、原生 Bearer 失效、原生草稿及幂等键复用。
- `frontend`：`npm run build` 通过。
- 小程序：13 个 JavaScript 文件语法检查通过；WXML/WXSS 编译通过，模拟器可见正常页面，最终 console 错误查询无匹配。
- 后端：本次认证修复后 `LOST_FOUND_INTEGRATION=1 go test -race ./... -count=1` 和 `go vet ./...` 通过；`git diff --check` 通过。
- `backend/tests/accounts` 使用独立临时账号覆盖禁用、密码重置、强制改密权限、微信绑定唯一约束、换绑及令牌失效；微信上游使用固定响应，未将其当成真实微信端到端验证。
