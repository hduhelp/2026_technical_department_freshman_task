# 校园失物招领系统 (Campus Lost & Found)

杭电助手 2026 招新小任务 - 开发赛道

## 📖 项目简介
这是一个用 Flask + SQLite + 原生 JS 写的轻量级失物招领平台。
因为今天刚坐车回到学校，时间非常紧。我评估了一下自己的水平，没有去碰 Next.js 或 FastAPI 这些复杂框架，而是选择了最稳妥的 Flask 单文件架构，把精力花在**数据库设计、Session 鉴权逻辑和解决跨域问题**上，确保我能交出一份真正能跑通的作品。

## 🚀 核心功能
- [x] 用户注册、登录、退出（基于 Flask Session 鉴权）
- [x] 发布失物/招领信息（包含类型、标题、地点、描述）
- [x] 关键词搜索（SQL LIKE 模糊匹配标题与描述）
- [x] 状态管理（发布者可标记“已找到”）
- [x] 权限控制（只有发布者能删除或修改自己的信息）

## 🐛 踩坑与开发思考
1. **跨域和Session丢失**：一开始我尝试前后端完全分离部署，结果浏览器一直报 CORS 错误，Session 也传不过去。查了很多资料后，我选择让 Flask 直接返回 `index.html`，同源部署后完美解决。
2. **SQL模糊查询的坑**：写 `LIKE` 语句时，一开始忘了在关键词两边加 `%`，导致搜什么都搜不出来。盯着代码排了很久才发现问题，这是很基础但真实的教训。
3. **密码安全**：我知道目前密码是明文存储在数据库里的，这是非常不安全的。由于时间关系，我先保证了功能跑通，后续一定会引入 `bcrypt` 进行哈希加密。
4. **工程结构**：虽然目前代码集中在单文件，但我已经按 `backend`、`frontend`、`docs` 做好了目录分层，为后续模块化打下基础。
