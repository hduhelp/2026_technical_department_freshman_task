# 杭电校园失物招领系统（杭电助手二面任务）
作者：软工2班 卢语翔（github:tiebanluyu）
## 目标
以杭州电子科技大学为背景，设计一个校园失物招领系统
在这个系统中，每个人可以拥有自己的账号，登录后在网站上发布自己丢失和拾取的物品。
发布完成后，所有访客均可以看到信息，如果有失主和拾取人看到这则通知，就可以通过联系方式让物品回归。
当物品回归之后，或者因为没有希望而放弃时，发布者可以回来修改状态为“已找到”和“已结束”

## 实现
本项目通过deepseek harness使用deepseek-v4.1-flash实现草稿，再由人工完成打磨
前端使用原生HTML和JS SPA书写，后端为python+fastapi+sqlite
前端为原生，没有必要单独设立进程，直接托管在fastapi下，减少CORS问题。

## 运行
要求先安装python环境
安装fastapi和uvicorn这两个依赖库
```bash
python -m pip install -r requirements.txt
```
运行以下代码
```bash
python -m uvicorn app.main:app --reload --port 8000
```
因为部分区域硬编码8000，目前暂时不支持修改默认端口

## 特色
1. 自动比较拾取地点等信息，寻找可能的丢失-拾取配对关系，并显示
2. 如果失物招领用户输入‘身份证’‘学生卡’等文本，将提示，引导前往有关部门或者联系本人，不建议网络广播，
3. 考虑到有的同学无力或不愿亲自处理，或者教职工家属，这些人可能拾取物品交由他人代管，
丢失物品由他人代找，所以区分发布者和保管人/联系人，发布者和保管人（如果正确填写）可以登录平台共同管理帖子。
