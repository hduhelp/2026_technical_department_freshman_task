## 作品简介

面向高校的失物招领互助平台，覆盖 首页 / 地图 / 发布 / 排行榜 / 我的 五大入口。

核心机制：
- **AI 特征验证** —— 认领者需答对物品特征才能解锁联系方式，杜绝冒领
- **信用分与助人为乐榜** —— 按月度维度结算，激励持续参与
- **校园热力图** —— 按地标聚合展示失物分布
- **悬赏与打赏** —— 调动积极性
