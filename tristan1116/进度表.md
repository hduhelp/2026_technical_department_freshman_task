## 已知坑（复用）

1. **Git Bash 传中文给 Windows 原生程序会被转成 GBK**（系统码页 CP936）
   - 请求体 → 写进临时文件，用 `curl --data-binary @文件`
   - URL 查询参数 → 用百分号编码（`校园卡` = `%E6%A0%A1%E5%9B%AD%E5%8D%A1`）
   - 生成编码：`printf '词' | python -X utf8 -c "import sys,urllib.parse;print(urllib.parse.quote(sys.stdin.read()))"`
2. **空列表要返回 `[]` 不能是 `null`** —— `make([]T, 0)` 而不是 `var s []T`，否则前端 `.map()` 崩
3. **MySQL 8.4 已禁用 `mysql_native_password`** —— 别照抄老教程的 `ALTER USER ... IDENTIFIED WITH mysql_native_password`，会报 1524
4. **DSN 必须带 `parseTime=True&loc=Local`** —— 否则时间字段扫描报错 / 差 8 小时
5. **改完代码要重启服务** —— Windows 会锁住 exe，先停掉旧进程再 `go build`
