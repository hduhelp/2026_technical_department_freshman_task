# 杭州电子科技大学失物招领系统

一个使用 Go、Gin、GORM 和原生 HTML/CSS/JavaScript 制作的面试演示项目。

## 功能

- 用户注册、登录、获取当前用户与退出登录
- 发布失物或招领信息；查看、编辑、删除自己的信息
- 关键词搜索、类型/状态筛选和分页
- 信息状态：寻找中 → 已找到 → 已结束
- 公开联系方式，便于失主和拾主直接联系

## 启动

需要 Go 1.27 或更新版本。

```powershell
cd wangcheng071029
go run .
```

打开 <http://localhost:8080>。首次启动会在当前目录创建 SQLite 数据库 `lost_found.db`。

## 技术说明

- Gin：定义 HTTP 接口。
- GORM：将 Go 结构体保存到 SQLite 数据库。
- JWT：登录成功后返回令牌；浏览器存入 `localStorage`，之后通过 `Authorization: Bearer <令牌>` 识别用户。
- `WHERE`：按类型和状态筛选；`LIKE`：搜索物品、地点和描述；`ORDER BY`：最新发布优先；`LIMIT`/`OFFSET`：分页。

## 演示脚本

1. 注册“小明”，登录后发布“校园卡”失物信息。
2. 退出并注册“小红”，发布“校园卡”招领信息。
3. 搜索“校园卡”，查看两条信息和联系方式。
4. 用小明重新登录，编辑自己的描述，再将状态依次标记为“已找到”和“已结束”。
5. 说明小红无法修改小明的信息，因为后端会校验 JWT 对应的发布者 ID。

接口可导入 `apifox-接口示例.json` 后在 Apifox 中测试。
