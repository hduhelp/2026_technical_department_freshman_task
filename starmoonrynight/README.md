# 失物招领系统（正式版 · 局域网部署 + 设计文档集）

> **当前状态**：✅ 已从设计稿落地为**可运行的正式系统**（Python + FastAPI + SQLite），**部署方式：仅校园/园区内网访问**
> **启动方式**：双击 [启动服务.bat](启动服务.bat)，浏览器打开 `http://127.0.0.1:8000`
> **局域网访问**：`http://10.41.74.75:8000`（同网络的其他电脑/手机直接打开，界面已适配移动端）
> **连通性自检**：双击 [局域网自检.bat](局域网自检.bat)（自动检查 IP、端口监听、防火墙与接口）
> **开机自启**：管理员运行 [安装开机自启.bat](安装开机自启.bat)
> **管理账号**：`admin` / `Admin@123456`　普通用户：`zhangsan` / `User@123456`

```powershell

# 2) 本机浏览器打开
http://127.0.0.1:8000

# 3) 其他电脑/手机（同一局域网）打开
http://10.41.74.75:8000
```

## 5. 上线（内网）前必做

1. **放行防火墙端口**（其他电脑才能访问）：
   ```powershell
   New-NetFirewallRule -DisplayName "失物招领系统 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Any
   ```
2. **修改管理员密码**（个人中心 → 修改密码）。
3. **配置开机自启**（可选但推荐）：管理员运行 [安装开机自启.bat](安装开机自启.bat)。
4. **执行一次备份**：数据库管理台 → 立即备份数据库，确认 `server/data/backup/` 有快照。
5. **执行一次自检**：双击 [局域网自检.bat](局域网自检.bat)，确认 6 项全绿。
6. **通知使用者**：把 `http://10.41.74.75:8000` 发到群或公告栏。
7. **运行回归测试**（可选）：`.venv\Scripts\python.exe server\tests_e2e.py`（应 73 项全过）。

> 部署细节、故障排查、数据库备份恢复、以及"将来若需对外发布"的备查方案，见 **[09-部署与运维说明.md](09-部署与运维说明.md)**。

## 4. 术语表

| 术语 | 含义 |
| --- | --- |
| 失物（LOST） | 用户丢失物品后发布的信息，记录 type = 1 |
| 招领（FOUND） | 用户拾获物品后发布的信息，记录 type = 2 |
| 记录（Record） | 失物与招领信息在数据层的统一称谓，见 `item_record` 表 |
| 发布人 | 创建该条记录的用户，是唯一有权编辑/下架该记录的角色 |
| 有效 | 记录状态为「发布中」，可被检索到 |
| 下架 | 记录状态置为「已结束」，不再出现在检索结果中，但数据保留 |
| 逻辑删除 | 通过 `deleted` 字段标记删除，数据不物理清除，便于追溯与误删恢复 |

## 5. 关键设计取舍（一句话版）

1. **单表统一失物与招领**：`item_record.type` 区分，避免两套结构重复，检索、收藏、统计均只需一套逻辑。
2. **地点两级收敛 + 详细地址自由填写**：先选「校内 / 校外」，再选字典地点，最后自由填写详细地址 —— 既有可筛选的结构化维度，又不限制用户表达。
3. **匿名是「前台匿名」**：`is_anonymous = 1` 只隐藏前台昵称与联系方式，`publisher_id`、操作日志、登录 IP 完整保留，管理员可查，避免匿名变成追责盲区。
4. **上交地址即首选联系方式**：拾获人常把东西交到服务台/宿管处，招领信息登记该地址后，详情页优先展示它与其电话，失主可凭证件直接前往领取，减少一次转述。
5. **认领不排他 + 72 小时自动断开**：允许多人同时认领由发布人择优，既避免"先到先得"错配，也用超时机制防止长期占位；标识用黄色「n 人认领中」/ 蓝色「暂未认领」在列表与详情页统一呈现。
6. **极简不等于无边界**：保留状态机、审计字段、错误码体系与鉴权，认领与私聊在既有表结构上增量扩展，无需重构。
7. **检索优先**：首页即检索入口，索引按「类型 + 状态 + 分类 / 区域地点 / 认领状态 + 时间」组合设计，保证列表接口在 10 万级数据下仍走索引。
8. **联系方式后置可见**：详情页联系方式需登录后查看，抑制爬虫批量抓取隐私。
