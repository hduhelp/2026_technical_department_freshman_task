# 失物招领系统

> 校园 / 园区失物招领平台。用户发布失物与招领信息、按地点与分类检索、提交认领申请并通过站内私聊沟通；管理员在后台维护信息、认领、用户与字典。
>
> **技术栈**：Python 3 + FastAPI + SQLite + 原生 HTML/CSS/JS（无前端构建步骤，由后端直接托管静态页面）

---

## 一、快速开始（从零开始，4 步）

需要 **Python 3.10 以上**（实测 3.12.14）。仓库不含虚拟环境，请按下面步骤自建。

```bash
# 1) 建虚拟环境
python -m venv .venv

# 2) 安装依赖
.venv\Scripts\python.exe -m pip install -r requirements.txt     # Windows
# .venv/bin/python -m pip install -r requirements.txt           # Linux / macOS

# 3) 初始化并启动（首次会自动建表并写入演示数据）
.venv\Scripts\python.exe run.py

# 4) 浏览器打开
#    http://127.0.0.1:8000
```

Windows 用户装完依赖后也可以直接**双击 `启动服务.bat`**。

> 首次启动会自动创建 `server/data/`（数据库、上传目录、备份目录）并写入演示数据：
> 5 个账号 + 8 条示例信息。数据文件不入库，属正常现象。

## 二、局域网访问

服务默认监听 `0.0.0.0:8000`，同一局域网内的其他电脑 / 手机可直接访问：

```
http://<本机IP>:8000
```

- 双击 **`局域网自检.bat`** 会自动检测本机 IP、端口监听、防火墙与各接口，并打印出可直接分发的访问地址。
- 首次让其他设备访问前，可能需要在**管理员 PowerShell** 中放行端口（只需一次）：

```powershell
New-NetFirewallRule -DisplayName "失物招领系统 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Any
```

### 启动 / 停止

| 操作 | 方式 |
| --- | --- |
| 启动 | 双击 `启动服务.bat`，或 `python run.py` |
| 启动（自动处理端口占用） | 双击 `手动启动.bat`（会先停掉已在运行的旧实例） |
| 停止 | 在服务窗口按 `Ctrl+C` |
| 开机自启 | 管理员运行 `安装开机自启.bat` |
| 连通性自检 | 双击 `局域网自检.bat` |

### 自定义端口 / 监听地址

支持环境变量覆盖，无需改代码：

```bash
set LF_PORT=8080          # 默认 8000
set LF_HOST=0.0.0.0       # 默认 0.0.0.0（允许局域网访问）
set LF_DATA_DIR=D:\lfdata # 数据目录
```

## 三、功能一览

| 模块 | 能力 |
| --- | --- |
| **账号** | 注册、登录（5 次失败锁定 15 分钟）、登出、令牌刷新、资料维护、头像上传、修改密码 |
| **发布** | 失物 / 招领、区域（校内 / 校外）+ 详细地址、分类、发生时间、描述、多图上传（自动压缩 + 缩略图）、匿名发布（前台匿名、后台留实名）、招领可登记「上交地址」、发布频率限制（60 秒 / 每日 10 条） |
| **检索** | 关键词（含通配符转义与结果高亮）、类型、分类、区域 + 具体地点、认领状态、时间区间、三种排序、物理分页 |
| **详情** | 图片切换与放大、联系方式登录可见（未登录脱敏）、上交地址优先展示、匿名脱敏、收藏、举报、同分类相关推荐 |
| **认领** | 提交申请（10–200 字说明）、**认领不排他**（可多人同时申请）、站内私聊、**72 小时超时自动断开**、发布人确认 / 解除、申请人撤回、管理员介入 |
| **个人中心** | 我的发布（编辑 / 上下架 / 删除 + 认领申请人面板）、我的认领（含倒计时）、我的收藏、资料维护 |
| **管理后台** | 数据概览（含认领完成率与 7 日趋势）、信息管理（发布人实名可见 + 强制下架留痕）、认领管理（查看私聊 + 解除）、用户管理（禁用 / 启用）、分类与地点字典维护 |
| **数据库管理台** | 表浏览 / 搜索 / 排序、行级增删改、SQL 控制台（写操作需授权）、一键备份、健康检查、CSV 导出、表结构查看 |

### 关键设计取舍

1. **单表统一失物与招领**：`item_record.type` 区分，检索、收藏、统计共用一套逻辑。
2. **两级地点收敛 + 详细地址自由填写**：先选「校内 / 校外」，再选字典地点，最后自由描述 —— 既可筛选又不限制表达。
3. **匿名是「前台匿名」**：`is_anonymous = 1` 只隐藏前台昵称与联系方式，`publisher_id`、操作日志、登录 IP 完整保留，管理员可查，避免匿名成为追责盲区。
4. **上交地址归招领**：物品由拾获人交到服务台 / 宿管处，因此该字段只在招领信息出现；详情页优先展示该地址及其电话，失主可凭证件直接前往领取。
5. **认领不排他 + 72 小时断开**：允许多人同时认领由发布人择优，避免「先到先得」错配；超时机制防止长期占位。
6. **联系方式后置可见**：详情页联系方式需登录后查看，抑制爬虫批量抓取隐私。

## 四、目录结构

```
.
├── run.py                     启动脚本（初始化数据库 + 启动服务）
├── requirements.txt           运行依赖
├── 启动服务.bat                一键启动
├── 手动启动.bat                启动（自动释放被占用的端口）
├── 局域网自检.bat              局域网连通性自检
├── 安装开机自启.bat            安装为开机自启（需管理员）
└── server/
    ├── main.py                应用入口、路由挂载、定时任务、统一异常处理
    ├── config.py              全局配置（全部支持环境变量覆盖）
    ├── db.py                  建表 DDL、演示数据、连接与通用 CRUD 封装
    ├── routers/               接口层
    │   ├── auth.py            注册 / 登录 / 令牌 / 资料 / 改密 / 头像
    │   ├── items.py           发布 / 检索 / 详情 / 编辑 / 上下架 / 收藏 / 图片
    │   ├── claims.py          认领申请 / 确认 / 解除 / 站内私聊 / 超时断开
    │   ├── admin.py           管理端：分类、地点、用户、信息、认领、统计
    │   ├── db_admin.py        数据库管理台接口
    │   └── meta.py            公共字典（分类、地点、站点配置）
    ├── services/              图片压缩与缩略图、占位图生成
    ├── utils/                 统一响应体与错误码、JWT、依赖注入与鉴权
    ├── web/                   前端页面（原生 HTML/CSS/JS，后端直接托管）
    └── tests_e2e.py           端到端接口自测（74 项）
```

运行时生成（不入库）：`server/data/`（`lostfound.db`、`uploads/`、`backup/`、`secret.key`）

## 六、部署说明

- **数据库**：单文件 SQLite，默认位于 `server/data/lostfound.db`，拷贝该文件即可迁移 / 备份；管理后台页提供一键备份。
- **上传文件**：`server/data/uploads/`，随数据库一起迁移。
- **密钥**：首次启动自动生成 `server/data/secret.key`，用于签发登录令牌；迁移时请一并拷贝，否则已登录用户会掉线。
- **公网访问**：服务本身监听私网地址，如需公网访问，请自行配置反向代理或内网穿透，并**务必先修改管理员默认密码**。
