\# 校园失物招领平台

纯前端项目，使用 HTML + CSS + JavaScript + localStorage 实现，无需后端环境，双击html即可运行。



\## 功能介绍

1\. 用户注册、登录系统，未登录用户无法访问主页，自动跳转登录页面

2\. 用户可以发布寻物启事或者捡到物品的招领信息

3\. 所有发布的信息以卡片形式展示，记录物品名称、详情、发布人、发布时间

4\. 仅发布者本人可以删除自己发布的招领信息，防止误删他人内容

5\. 支持退出登录，清空当前登录状态

\## 运行方式

1\. 将项目完整解压

2\. 打开项目文件夹，直接双击 `index.html`

3\. 先注册账号，登录后即可使用全部功能

> 数据存储在浏览器本地 localStorage，清除浏览器缓存会清空所有信息。
